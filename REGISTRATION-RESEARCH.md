# Registration onboarding evidence — 2026-10-26

The tutorial is scenario-based for mainland Chinese learners, not a claim of mainland-network testing. No account was created, SMS completed, or subscription purchased. The signed-in browser redirected public login/signup entry URLs to the existing account; no private account screenshot was published. Windows remains untested.

Cross-checked primary sources:

- https://help.openai.com/en/articles/7947663-chatgpt-supported-countries — mainland China is absent from the supported list.
- https://help.openai.com/en/articles/9131992-chatgpt-and-api-services-in-unsupported-countries-and-territories — an existing account does not remove location restrictions; travel and payment support are distinct from page reachability.
- https://help.openai.com/en/articles/8983040-what-does-phone-verification-look-like — ordinary ChatGPT account creation generally does not require phone verification; desktop Codex may require it. Verification uses supported mobile numbers; no promise for +86 or shared/VoIP numbers.
- https://help.openai.com/en/articles/7996703-troubleshooting-chatgpt-error-messages — separately corroborates desktop “Phone number required”.
- https://help.openai.com/en/articles/8505609-ive-received-a-verification-email-i-didnt-request — email ownership and verification links.
- https://help.openai.com/en/articles/9889414-why-am-i-being-asked-to-verify-my-login — email OTP versus push verification; latest code and expiry handling.
- https://help.openai.com/en/articles/7426629-why-cant-i-log-in-to-chatgpt — original authentication method, partially created account, verification loops, suspicious-login cooldown, support.
- https://learn.chatgpt.com/docs/quickstart — same ChatGPT account signs into the desktop app; Codex selector.
- https://learn.chatgpt.com/docs/pricing — Free included subject to rollout and limits. No blanket promise that the entire course can run free, no fixed price copied.
