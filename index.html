检查器 + 人工复核

需要

  • 一台能解压、管理文件的电脑。
  • 合法可用、支持本地文件读写的 Codex 或兼容工具账户与额度。
  • 下载学习包，选择其中 workspace 作为工作目录。

工具费用自行承担；主线不需要 API Key、不要求连接私人账户。新手先用包内虚构资料。

完成后带走

  • 可迁移的个人背景与输出偏好。
  • 一份清楚的项目工作约定。
  • 两个 Skills、实际产出与自己的验收记录。

文件包不是自动运行的软件服务。能否正确执行，取决于所用工具、权限、输入和你的检查。

这套课的展示方式

用具体步骤、完整材料和可检查结果说明解决问题的方法。所有课堂人物与业务数据均为虚构，不展示个人社媒作品，不虚构企业客户或学员成果。
