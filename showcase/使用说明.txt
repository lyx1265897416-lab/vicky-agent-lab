成果看板 · 使用说明

这是什么
课程额外提供的可视化查看器。它展示 JSON，不在网页中运行 AI，也不是 Codex 自带界面。课程人物与业务数据均为虚构。

1. 解压这个 ZIP，保留 index.html 与 showcase、media 文件夹的位置关系。
2. 双击 index.html，用 Chrome、Edge 或 Safari 打开；不需要安装软件或运行服务器。
3. 先查看内置样例：会议行动看板、研究简报、个人工作区。
4. 完成课程第 6 / 7 课后，在自己的 workspace/outputs 中找到 .json 结果。
5. 点击“导入我的 JSON”，一次选择一份 meeting-actions 或 research-brief 格式的结果。文件不超过 1 MB；请不要选择 .md。
6. 可筛选任务、切换简报分类、查看引用。自己导入的结果只带 JSON 中的引用，不包含完整原文，必须回工作区打开 source_files 对照。
7. “导出 JSON”下载当前结果；“恢复样例”清除当前导入状态。刷新或关闭页面也会丢失导入状态，请保留原始 JSON。

文件说明
- index.html：打开这个页面开始。
- showcase/：页面运行所需的代码、样例数据与样式，不要拆散。
- media/evidence/actions.json、brief.json：课程 case-a 的历史 CLI 输出，可用于练习导入。
- 页面里的课程链接需要联网；本地查看和导入不需要。

没有看到结果怎么办
- 整个文件夹解压后再打开，不要在压缩包预览内运行。
- 页面只有标题没有卡片：确认 showcase/data.js、viewer.js 未丢失，浏览器允许本地脚本。
- 格式不匹配：保留 kind、source_files、evidence 等课程约定字段，不要把 Markdown 改后缀伪装成 JSON。
- 任务缺负责人或期限：待确认是正确的展示，不要为了填满卡片而猜答案。
- 本工具不保存或上传导入内容。每次打开需重新选择文件。

复现与边界
会议清单与简报对应课程 case-a 虚构练习的一次真实 Codex CLI 运行；模板工作区展示预期文件位置，不连接你电脑上的真实文件。
看板能打开，只能证明显示正常。引用是否支持结论、有没有遗漏、任务范围是否正确，仍需按课程验收清单核对。
