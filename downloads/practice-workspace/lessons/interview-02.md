# 02 / 每次一个问题，练出真实细节

陪练需要根据你的上一句回答继续追问。一次生成二十个问题容易变成背题，也无法检查你是否能解释自己的决策。这一课用四轮问答，先练最重要的一次项目迭代。

首轮先介绍项目，后续回答只使用材料里已有的事实。问到未知内容，直接说“这部分没有记录”。在教学材料中扮演虚构候选人是一种练习，之后不能把这些经历写进自己的简历。

正常情况下，助手提出一个问题后应停下来等你。如果没有停，直接要求恢复单题模式。文字练习只看回答内容，不对声音、自信程度或肢体语言作判断。

## 跟做
1. 发送下面的调用指令。
2. 先自己回答第一题，再等下一题；完成四轮。
3. 第四轮结束后要求复盘，检查报告中的引用是否确实来自你的回答。

## 发给 Codex
```text
使用 $aigc-interview-coach 的模拟模式，读取 samples/interview-film.md。进行四轮文字面试，每次只问一题并等待我回答，先不要给参考答案。围绕我的回答追问，不补造经历。结束后再复盘。
```

## 应该看到
每次只有一个问题；回答后出现相关追问。复盘包含原话和下一步练习，没有录用概率。
