# 01 / 提交完整题目和自己的原稿

写作复盘先看你是否回答了题目，再看论证与表达。没有题目，AI 无法可靠判断任务回应。这个样例只处理 Task 2 文字作文，不处理图表识别，也不评估整场 IELTS 总分。

解压实战包，将 practice-workspace 作为本地工作目录。先读取 samples/ielts-volunteer.md：其中有原创题目与完整练习作文。不要先读修改稿；用原稿体验如何发现问题。

首版尚未经过雅思教师复核，因此只用作学习工作流示范。反馈参考四个官方维度组织，但不提供分数估计、考试认证或提分承诺。

## 跟做
1. 下载并打开工作区，完成下方目录检查。
2. 让 Codex 读取 samples/ielts-volunteer.md，确认题目与正文分开。
3. 用中文概括题目要求和作者立场，再开始诊断。

## 发给 Codex
```text
请先列出当前工作目录，确认有 AGENTS.md、samples、resources 和 .agents/skills。只读取这些课程文件。告诉我找到的两个 Skill 名称；不要搜索其他目录，不修改全局配置。
```

## 应该看到
目录正确，题目和正文完整；助手能区分题目要求、文章立场与缺失材料。

## 排错
如果你只粘贴了一个段落，助手应提供局部反馈，不评价整篇回应与结构。没有题目时先补题目。
