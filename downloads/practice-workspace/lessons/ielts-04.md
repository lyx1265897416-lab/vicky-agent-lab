# 04 / 换题练习，建立个人错误记录

同一篇文章改好了，只说明这次修改完成。下一步要换题，独立写出同类结构，观察问题是否再次出现。模型不能仅凭两篇文章断言你的能力永久提升。

resources/error-log.md 提供一个简单记录表：问题类型、原句、修改理由、复练题和复查结果。只保留反复出现且确认成立的问题，不把每条风格建议都变成禁令。

使用交通题检查“合理表达是否被误改”，使用远程办公题检查“重复形容词与段落功能”。这些样例帮助你学会审查 AI，而不是被动接受全部批注。

## 跟做
1. 选择一个确认成立的问题写进 error-log.md。
2. 让 Codex 给一个针对该问题的短练习，先不显示答案。
3. 完成后复查；再独立写新题段落，记录这次是否再次出现问题。

## 发给 Codex
```text
使用 $ielts-writing-coach 的专项练习模式，读取 outputs/ielts-02.json，只选一个已确认的问题。先给一道新题上的短练习，不给答案；等我作答再反馈。把实际结果记录到 outputs/error-log.md，不把练习完成写成考试提分。
```

## 应该看到
得到一份有原句、理由与复练记录的错误表；能够指出 AI 建议中一项应保留原表达的情况。

## 排错
如果练习同时考太多内容，收窄到一个问题。若要使用数字估分或售卖教师级批改，先完成教师复核和独立样本验证。
