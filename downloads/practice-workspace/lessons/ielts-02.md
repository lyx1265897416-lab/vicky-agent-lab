# 02 / 从原句出发，只处理最重要的问题

这一课观察三类问题：明确语法错误、论证或立场问题、可选表达建议。它们不能混在一起。比如复数主语配 has 可以明确指出；是否要换一个词则可能只是风格选择。

预置志愿服务作文有一个刻意设置的立场冲突：开头反对全面强制，结论却说应该强制。先解决这一冲突，比替换几个高级词更重要。反馈应引用冲突位置，并请作者确认真实观点。

优先处理三个问题。AI 给的局部示范只是辅助，你仍需要自己解释为什么修改。直接采用整篇改写，无法确认你是否掌握。

## 跟做
1. 发送下面的诊断指令。
2. 逐条在原文找到引用，标记“明确问题／可选建议／待确认”。
3. 先选择一个问题自己修改；只在卡住时请求局部示范。

## 发给 Codex
```text
使用 $ielts-writing-coach 的首次诊断模式，读取 samples/ielts-volunteer.md。先核对题目和立场，再给最多三个优先问题。每条引用原句，区分明确错误和可选建议，不估分，不整篇代写。将结果按 resources/report-format.md 保存到 outputs/ielts-01.json，并另存 Markdown。
```

## 应该看到
每条问题都有原文依据与具体修改动作；不会因文章没有生僻词而扣“分”。

## 排错
发现 AI 批评原文里不存在的句子时停止采用该条，让它重新定位。它若直接给分，提醒首版只做有依据的诊断。
