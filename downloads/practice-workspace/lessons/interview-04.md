# 04 / 换项目，再确认真的学会了

会复述参考答案不等于学会面试。先选复盘中最薄弱的一项，用真实事实重答，再换一个项目测试是否仍能讲清。不要把示例的细节移植到自己的经历。

使用 samples/interview-image.md 或 interview-interactive.md 做迁移练习，或者填自己的 project-facts.md。将“已做的动作”和“下一次打算做的动作”分开；后者可以体现复盘，但不能当作历史成果。

长期资产是自己的项目证据库：每次补充一条真实决策、一次失败修正、一份可公开成果。对外分享前检查授权与个人信息，复盘文件默认留在本地。

## 跟做
1. 针对旧报告中的一项缺口重新回答，要求比较两次原话。
2. 换一个项目，独立完成两轮追问，不先看样例答案。
3. 按 resources/quality-checklist.md 自查，将本次通过、未通过和待确认项记录到 outputs。

## 发给 Codex
```text
使用 $aigc-interview-coach 的重练模式，读取 outputs/interview-01.json。先选一项证据不足的回答，让我重答；我答完后逐句比较改进，别添加材料外事实。随后用 samples/interview-interactive.md 换题测试，每次一题。
```

## 应该看到
能区分事实、推测与计划；能解释一次具体取舍；更换项目后仍能形成有证据的回答。

## 排错
重答只是变长时，要求指出新增了哪项可核实信息。模型夸奖或给高分不代表达到验收要求。
