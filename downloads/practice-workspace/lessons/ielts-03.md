# 03 / 自己修改，再检查有没有真正解决

修改复查必须同时看到题目、原稿和修改稿。否则 AI 可能只是在重新批改新文章，而没有验证旧问题是否解决。原稿不能被覆盖。

例如把 has 改成 have 可以解决局部主谓问题，但立场矛盾需要回看引言、主体和结论。修改结果用“已解决、部分解决、未解决、待确认”描述，比一条笼统的“进步很大”更有用。

页面的修改对照只展示人工整理的教学片段，不代表真实学员成果。你的修改可以有多种合理写法，不要求逐字匹配样例。

## 跟做
1. 复制原稿为 outputs/ielts-revision.md，自行修改三个重点问题。
2. 把原稿路径、修改稿路径和旧报告一起交给 Codex。
3. 将新的 JSON 导入“我的练习”，核对每个旧问题以及新增问题。

## 发给 Codex
```text
使用 $ielts-writing-coach 的修改复查模式，对照 samples/ielts-volunteer.md、outputs/ielts-revision.md 和 outputs/ielts-01.json。逐项说明旧问题是否解决及新问题。保留我的立场，不整篇重写。保存新报告 outputs/ielts-02.json；source 同时包含标注版本的原稿和修改稿，quote 必须逐字可定位。
```

## 应该看到
原稿仍在；每个重点问题都有复查结论，且引用对应版本的文字。

## 排错
若模型将你的立场改成相反观点，恢复原稿并明确立场。改得更长或词更难，不自动等于更好。
