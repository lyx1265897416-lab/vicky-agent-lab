# 反馈依据与边界
核对日期：2026-10-27。参考而非复制官方评分表。
- IELTS 官方写作说明：https://ielts.org/take-a-test/preparation-resources/writing-test-resources
- 官方描述表：https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf

任务回应：有没有回应题目各部分；立场是否清楚一致；观点有没有解释和支持。
连贯与衔接：段落是否各有功能；信息推进是否清楚；连接方式是否合理，不按连接词数量评价。
词汇：选择是否准确、自然、适合上下文；不把复杂词等同于高水平。
语法：句子是否表达清楚；结构是否适合意图；局部错误与全文表现分开。

首版不对接任何官方考试评分系统，不提供分数估计。以下是课程作者的流程设计，需要教师复核，不是官方逐条评分规则。
- 优先处理立场冲突、缺失回应、影响理解的问题；局部明确错误也应指出。
- 修复原句后检查是否改变作者立场或事实。
- 同一篇改稿变好不能证明新题独立作答进步。
- “合理表达不应硬改”样例中有意保留自然常见词，不能为了显示批改工作量而制造问题。
