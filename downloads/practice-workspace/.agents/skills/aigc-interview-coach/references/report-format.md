# 练习报告格式 v1
输出 UTF-8 JSON 对象，不加 Markdown 围栏。文件小于 200 KB。网页支持以下字段；不支持 HTML。

```json
{
  "version": 1,
  "kind": "interview",
  "title": "本次练习",
  "source": "本轮实际输入与回答全文（多版本请加版本标签）",
  "summary": "有依据的主要发现；注明是 AI 反馈待复核",
  "evidence": [
    {"quote": "实际输入", "issue": "这条原话对应的问题或优势", "action": "可执行的下一步", "status": "需要补充"}
  ],
  "nextPractice": "一道迁移练习，不直接给答案",
  "disclaimer": "练习反馈，不代表考试分数或录用结果。"
}
```
kind 只能为 interview 或 ielts。evidence 为 1–12 条。每条 quote 是 source 中非空的逐字连续片段；不能拼接或改写引文。缺失信息可引用最近的相关原话说明缺口；没有任何实际回答就先问问题，不制造引文。所有文本字段都需非空。不要把不真实的内容加进 source 来通过校验。

status 可以使用已有证据、需要补充、明确问题、可选建议、待确认、已解决、部分解决、未解决。评价必须由上下文支持，不能只凭引文匹配得出结论。

既有报告保留；用递增编号写新报告。输出 JSON 和 Markdown 后向用户提供路径。练习数据留在用户工作区，不提交 Git，不上传公开网站。网页导入不会向服务器提交文件，但用户主动发给 AI 工具的内容由对应工具处理。
