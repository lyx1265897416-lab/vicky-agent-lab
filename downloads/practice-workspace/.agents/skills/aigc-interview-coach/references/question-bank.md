# 问题库：按答案追问，不照单宣读
这些是课程原创练习问题，不是任何公司的内部面经。每次只选一个最有价值的问题。

| 能力 | 主问题 | 何时追问 | 追问方向与观察依据 |
|---|---|---|---|
| 创意判断 | 目标受众是谁？ | 只说所有人 | 请描述一个使用情境，观察是否能落到具体需求 |
| 创意判断 | 为什么选这个视觉方向？ | 只说好看 | 比较一个被放弃的方向，观察是否解释取舍 |
| 创意判断 | 如何解释参考与原创的关系？ | 只列参考图 | 哪部分借鉴结构、哪部分自己设计，观察来源边界 |
| 创意判断 | 用户第一眼应看到什么？ | 元素全重要 | 给出阅读顺序与验证方式，观察优先级 |
| 流程选择 | 为什么用这个模型？ | 只说最新 | 当时实际比较了哪些效果与限制，未知不补造 |
| 流程选择 | 哪步需要人工决定？ | 说全自动 | 找一个具体决策，观察对能力边界的理解 |
| 流程选择 | 时间缩短一天怎么办？ | 仍全做 | 保留关键验收，观察范围控制 |
| 流程选择 | 怎样让下一次更快？ | 只想加工具 | 指出可复用材料或步骤，观察是否来自真实重复问题 |
| 迭代 | 最不满意的一版是什么？ | 没有失败 | 选一个局部不足，观察能否具体描述 |
| 迭代 | 当时如何定位原因？ | 一次改很多 | 区分观察与推测，观察试验是否能提供信息 |
| 迭代 | 修改后怎样确认有效？ | 凭感觉 | 对照相同标准，观察是否有可展示变化 |
| 迭代 | 模型不稳定怎么办？ | 不断重试 | 解释何时换方案、何时缩范围，观察止损判断 |
| 协作 | 哪部分是你独立完成？ | 只说我们 | 明确本人和他人职责，不把团队成果全归个人 |
| 协作 | 怎样交给下一个同事？ | 发个文件 | 描述格式、版本与注意事项，观察交接可用性 |
| 协作 | 收到冲突反馈怎么办？ | 全部接受 | 核对目标与优先级，观察如何收敛而非讨好 |
| 协作 | 素材如何确认可用？ | 网上的都行 | 给出来源和授权检查，不擅自作法律结论 |
| 结果 | 你说效果更好，证据是什么？ | 没基线 | 确认比较对象、条件和局限，不强迫提供不存在的数据 |
| 结果 | 没有投放数据怎样讲成果？ | 准备造数字 | 说明验收、制作证据和未知商业结果 |
| 结果 | 重新做一次会改什么？ | 只换更强模型 | 联系本次问题提出可验证调整 |
| 结果 | 哪项结论还不确定？ | 声称全部确定 | 请描述未测试条件，观察对证据边界的认识 |
