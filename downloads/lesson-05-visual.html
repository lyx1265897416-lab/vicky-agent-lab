切到真实 Codex 前，先对照

先回到桌面应用的 Codex 本地项目（This computer / Local），确认 workspace 是主文件夹。课程截图与视频不会操作你的电脑；请在自己的 Codex 中执行下方指令。

模板和生效位置不同

resources/templates/AGENTS.md 是素材；要放到 workspace/AGENTS.md，与 START.txt 同级。别上传成网页附件，别写进 .agents，也别保存成 AGENTS.md.txt。

“新对话”不是读取成功的证明

配置完成后重新开始同一目录的任务；CLI 要重新启动会话。若规则仍旧，重启 Codex。显式读取能检查内容，但不能证明自动发现成功；自动加载仍可能受上层规则或覆盖文件影响。

找不到入口？复制这条只读核对指令

在自己的 Codex 消息框发送。它用于找路径和检查文件，不会替你完成安装或生成作业。

请只读检查当前任务的实际工作目录，先报告完整路径，并确认根目录 START.txt 是否存在。然后逐一检查这些相对于该目录的路径：AGENTS.md；resources/templates/AGENTS.md。对每项报告“存在 / 不存在”、完整路径和文件开头几行；若客户端支持，提供可点击的本地文件链接。不搜索工作区外、不创建或修改文件、不把示例文本当成真实检查结果。读不到就报告原因，不补造文件。
Mac / Windows 入口速查与核查范围

先点桌面应用，让快捷键作用在应用上，别在课程网页里按。打开文件夹：Mac ⌘O / Windows Ctrl+O；搜索文件：⌘P / Ctrl+P；显示文件树：⌘⇧E / Ctrl+Shift+E；新聊天：⌘N / Ctrl+N。快捷键可被用户改过，失效时到 Settings → Keyboard Shortcuts 搜索 Open folder、Search files、Toggle file tree 或 New chat。

本轮依据 2026-10-24 官方文档核对，并检查课程浏览器交互；未直接操控 Mac / Windows 的真实 Codex 客户端，不能称为双平台逐按钮实测。具体界面以所用版本为准。
