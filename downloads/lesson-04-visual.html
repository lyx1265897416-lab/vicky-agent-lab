1. 复制虚构背景模板

要求只创建两份 context 文件，保留资源模板。

切到真实 Codex 前，先对照

先回到桌面应用的 Codex 本地项目（This computer / Local），确认 workspace 是主文件夹。课程截图与视频不会操作你的电脑；请在自己的 Codex 中执行下方指令。

个人背景不是内置设置页

本课的 profile.md / preferences.md 是普通 Markdown 文件，不是 ChatGPT 的个人资料、记忆开关或账号设置。先复制模板，再在第 4 课第 2 步填写自己的背景；只复制虚构模板还没完成个性化。

看不到左侧 context

创建成功后才有两份文件。用应用文件搜索或系统文件管理器打开它们。编辑后保存，再让 Codex 读取；新的聊天不会自动知道你在其他聊天说过什么。

找不到入口？复制这条只读核对指令

在自己的 Codex 消息框发送。它用于找路径和检查文件，不会替你完成安装或生成作业。

请只读检查当前任务的实际工作目录，先报告完整路径，并确认根目录 START.txt 是否存在。然后逐一检查这些相对于该目录的路径：context/profile.md；context/preferences.md。对每项报告“存在 / 不存在”、完整路径和文件开头几行；若客户端支持，提供可点击的本地文件链接。不搜索工作区外、不创建或修改文件、不把示例文本当成真实检查结果。读不到就报告原因，不补造文件。
Mac / Windows 入口速查与核查范围

先点桌面应用，让快捷键作用在应用上，别在课程网页里按。打开文件夹：Mac ⌘O / Windows Ctrl+O；搜索文件：⌘P / Ctrl+P；显示文件树：⌘⇧E / Ctrl+Shift+E；新聊天：⌘N / Ctrl+N。快捷键可被用户改过，失效时到 Settings → Keyboard Shortcuts 搜索 Open folder、Search files、Toggle file tree 或 New chat。
