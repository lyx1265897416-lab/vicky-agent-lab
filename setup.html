在中国大陆：先看这条实际限制

截至 2026-10-26，中国大陆不在 OpenAI 公布的 ChatGPT 支持地区名单中。仅有国内邮箱、+86 手机号和大陆使用环境，不能照着本课承诺完成官方 Codex 注册与使用。已有账号、网页能打开、买了订阅，都不代表所在地受支持。

中国大陆用户：现在怎么安排，才不会卡在第一天？
  1. 先查“当前使用所在地”，不是国籍。中国籍用户实际在受支持地区学习或工作，可继续核对自己的账号条件。人在大陆，即使已有海外注册的账号，也不能据此保证可用。
  2. 先区分两种故障。网页打不开，是访问问题；出现 unsupported_country 或“所在国家/地区不受支持”，是可用性问题。换邮箱、重装应用、充值都不能把不支持地区变成官方支持地区。
  3. 先完成不用 Codex 的准备。读第 1 课概念，下载并解压课程包，在文本编辑器里草拟个人背景、任务说明和验收标准。现在可以“写好材料”，但不能标成“已运行 Agent”或“已安装并调用 Skills”。
  4. 再决定实操工具。若使用你所在地正式提供的其他 AI 工具，概念与任务拆解可以先练；本课的 Codex 按钮、AGENTS.md 自动读取和 Skills 发现机制，须在该工具上另行核验，不能原样照搬。全套 Codex 实操应等具备使用条件后继续。
不要把“买账号 / 代注册 / 接码 / 代充”当作课程前置步骤。代理或 VPN 也不等于获得官方地区支持；本课不承诺通过这些方式实现稳定使用。准备购买课程的学员，请先完成这节可用性判断。

符合使用条件：从打开官网到完成注册，逐步做

下面是依据官方账号文档整理的操作路线。当前浏览器已有登录态，未重新创建账号；注册按钮位置、密码与验证码的先后顺序可能因账号与版本不同。按屏幕当前提示走，不要寻找截图里不存在的按钮。

先准备 3 样东西① 能自己收信的长期邮箱，或已有的 Google / Apple / Microsoft 账号。② 可在所在地正常使用官方服务的浏览器与网络。③ 若 Codex 要求手机验证：自己控制、受支持且能接收验证的手机号码。

  1. 01 · 在浏览器打开官方入口

    先打开 chatgpt.com ↗。未登录时，寻找“注册 / Sign up / 免费注册”，或从“登录 / Log in”页进入创建账号。不要先去 API 开发者控制台，也不用先绑卡。

    看哪里：出现账号创建或登录方式选择页。若直接进入你自己的聊天主页，说明已有登录态，去下方“账号验收”即可；不要为跟课再建一个账号。

  2. 02 · 选定一种以后继续使用的登录方式

    邮箱路线：在 Email address / 邮箱框填自己的邮箱，点击 Continue / 继续。QQ、163 等邮箱能否实际收到验证、是否被接受，以页面与收信结果为准；不承诺某个邮箱品牌一定成功，也不把 Gmail 当成必需品。

    第三方路线：若页面提供 Continue with Google / Apple / Microsoft，选你已经拥有且能正常登录的账号，在对应服务的官方页面完成授权。以后优先使用同一个按钮、同一个账号。不要来回试多个邮箱，以免建出不同账户。

    看哪里：显示你选择的邮箱或登录服务；记录“邮箱登录”或“Apple 登录”等方式，不记录密码和验证码。

  3. 03 · 按页面要求完成密码与邮箱验证

    若页面要求设置密码，在该官方页面自己设置并妥善保存；若直接要求一次性验证码，就去邮箱取码。打开邮箱收件箱，也检查垃圾邮件。按邮件与网页要求，输入最新验证码，或点击 Verify email address / 验证邮箱链接，再回原注册页面继续。

    手机号登录是另一个可能出现的选项，取决于地区与账号；没有这个按钮就用已提供的方式。不要把“邮箱验证码”误当作后面可能出现的“手机验证码”。

    看哪里：验证提示消失、流程继续。收到欢迎邮件但仍未激活：回官方登录页，按原方式登录，完成剩余提示。

  4. 04 · 完成页面实际出现的资料与确认

    如要求姓名、生日或其他必要资料，如实填写；阅读页面条款，由你本人确认。出现人机验证时本人操作。不同账号的页面顺序可能不同，不要为了追上教程跳过屏幕提示。

    看哪里：进入自己的 ChatGPT 页面；在个人菜单 → Settings / 设置 → Account / 账号核对账号。Apple 的“隐藏邮箱”可能显示转发地址，后续仍用同一个 Apple 账号登录。

  5. 05 · 把账号用于桌面端 Codex

    完成下方自己系统的安装步骤，从桌面应用点击 Sign in / Log in，选刚刚使用的登录方式。浏览器完成后返回应用；若询问“打开应用”，确认返回刚安装的官方应用，再切到 Codex。

    看哪里：桌面端能进入 Codex。若要求手机号，先看下一块；如果没有 Codex 或没有额度，去“账号验收”检查，暂时不要付款。

如果出现 Verify your phone number

这是“验证手机号”。普通 ChatGPT 注册通常不要求手机验证，但桌面端 Codex 可能会要求；两者不矛盾。

  1. 在左侧区号下拉选号码实际所属地区，再填自己控制的受支持手机号码。图里的 +1 是界面示例，不要照抄。
  2. 点 Send code / 发送验证码，在页面指定的短信或可用的 WhatsApp 渠道收码，回原窗口提交。
  3. 没有受支持号码或收不到码，就停在此步查官方说明。邮箱、验证器不能替代这次必需的手机验证；不使用共享接码号码。

如果你只有 +86 号码，不能假定可用：大陆目前不在支持名单中。按实际区号和官方提示判断，不改成不属于自己的区号。

卡住了？按报错找处理方法

官网打不开 / 一直空白

先核对地区支持，再查 官方服务状态。如果实际位于受支持地区，可换更新的浏览器或无痕窗口测试；受管理网络请找 IT。打开网页不等于账号符合使用条件。

收不到邮箱验证码 / 验证码过期

核对拼写，检查垃圾邮件和拦截，按页面倒计时再请求一次，用最新的码。邮箱已经不能登录就先处理邮箱访问；不要买一个验证码代收服务。

Wrong authentication method / 账号已存在

返回“登录”，用创建时的方式。Google 注册就先点 Google；Apple 隐藏邮箱就先点 Apple。不要把账号已存在当成需要继续重复注册。

unsupported_country / 地区不支持

停止重试，回到地区判断。若确实已返回受支持地区仍报错，可清理该站点缓存、试无痕窗口，再联系官方支持；这不是在大陆直接可用的方法。

Checking your browser / 可疑登录 / 操作太频繁

地区受支持的前提下，检查站点 JavaScript 与 Cookie、扩展是否干扰验证；按错误提示等候。官方对可疑登录建议可等待最多 1 小时再尝试，别不停提交。企业设备的代理与安全设置由 IT 处理。

网页已登录，但桌面仍在欢迎页

回桌面应用重新发起登录，核对浏览器和应用是否同一账户，并处理返回应用的提示。桌面提示 Phone number required 时看上面的手机验证；找不到 Codex 时查版本与组织权限。

走到哪一步，才算准备好了？

A · 账号完成

自己的账户可登录；知道邮箱与登录方式；要求的验证已完成。

B · Codex 可用

桌面应用可进入 Codex；手机验证（若要求）已完成；账号或组织允许使用且有可用额度。

C · 课程可运行

选中课程 workspace；做完下方第 7–9 步，真实文件能读、能写、能找回。

本课采用 ChatGPT 账号登录，入门不需要先创建 API Key。当前官方定价页列有 Free 的 Codex 使用方式，但受账号开放情况与额度影响；不保证免费额度足够学完整套课。先验收 B，再决定是否需要付费。课程费、ChatGPT 订阅、API 用量不是同一笔费用。

WHEN SOMETHING GOES WRONG

按你看到的问题，回到正确的一步。

我只看到 ChatGPT 网页，找不到本地目录

确认是从应用程序 / 开始菜单打开桌面应用，再切到 Codex。网页附件上传与授权本地文件夹是两件事。回到本平台第 2、3 步。

登录成功却找不到 Codex，或提示没有额度

先更新官方应用，核对账号和组织是否提供 Codex。额度用尽按账户的重置或方案提示处理；不要反复发送测试。课程本身不包含工具额度。

下载完成却找不到 ZIP

打开浏览器下载列表，使用“在 Finder / 文件夹中显示”。Mac 可能已自动解压；Windows 需完成“全部解压”。不要重复创建多个不清楚的副本。

Codex 报告的路径不对，或 START.txt 不存在

停止写入。在系统文件管理器找到直接包含 START.txt 的 workspace；重新选择该文件夹，在它的新任务中重做只读检查。不要让 AI 搜索整台电脑来弥补选错目录。

有两个 workspace，究竟用了哪个

比较 Codex 报告的完整路径与文件管理器地址。Mac 在 Finder 的“显示”菜单开启“显示路径栏”；Windows 点击资源管理器地址栏查看完整路径。重名不等于同一个文件夹。

只有聊天里的文字，outputs 里没有文件

确认当前任务有文件工具与工作区写权限；在同一任务单独发写入指令。若工具报错先解决错误，不能把聊天回复“已保存”当成成功。

文件存在但打不开，或打开的是别的副本

让 Codex报告产出的完整路径，在 Finder / 资源管理器沿该路径打开。用文本编辑器（Mac 文本编辑 / Windows 记事本）打开 .md；也可使用应用文件预览。

Windows 没有 python3，后续检查器还能用吗

先发下方“可选检查器”指令，仅检测已有 Python。Windows 常见命令为 py -3 或 python，Mac 常见 python3；有 Python 3 才运行。没有时用课程人工验收表，不把未运行写成已通过。

看不到 .agents 或后缀不对

这是第 6 课才安装的目录，新包没有它是正常的。Mac 用 ⌘+Shift+. 切换隐藏文件显示；Windows 在“查看 → 显示”开启隐藏的项目和文件扩展名。检查 SKILL.md，而非 SKILL.md.txt。

重开应用以后，还要重装一遍吗

不用。打开同一 workspace 项目或重新选择原目录，创建新任务。先让工具读 START.txt 验证路径，再继续课程。不要把“新任务”理解成新建一套文件夹。
