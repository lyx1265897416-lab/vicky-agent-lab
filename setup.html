01
Mac · 系统菜单与浏览器

先确认电脑与下载入口

  1. 点击屏幕左上角苹果菜单 →“关于本机”，记下芯片和 macOS 版本。看到 Apple M 系列即 Apple Silicon；看到 Intel 则不能照搬 Apple Silicon 安装包。
  2. 打开下方官方桌面入口，选择 macOS 下载。2026-10-26 在官网实测下载到 ChatGPTInstaller.dmg 小型安装器。最低系统版本和芯片支持以官方当次提示为准；本轮未验证 Intel 安装。
  3. 准备可正常访问官方服务的网络与自己的账户。你需要一台可安装应用、可读写本地文件的电脑；手机用于看课可以，不能替代这条桌面实操路线。

打开官方桌面下载入口 ↗

02
Mac · 下载文件夹 / Finder

安装到“应用程序”，再打开

  1. 浏览器下载完成后，打开 Finder（访达）→“下载”，双击刚下载的安装文件。文件名可能随版本变化，以官方页面刚下载的文件为准。
  2. 当前官网主入口：打开 ChatGPTInstaller.dmg 后，双击中央的 Install ChatGPT，按安装器提示完成安装。若下载的是完整 DMG，并同时看到 ChatGPT 应用与 Applications 文件夹，则把应用拖到 Applications 等待复制。两种窗口不同，不要在小型安装器里寻找 Applications。
  3. 关闭安装窗口。在 Finder 左侧打开“应用程序”，找到 ChatGPT 并双击启动。不要每次都从 .dmg 安装盘启动。首次系统打开提示需核对应用名称与来源。
做到这里，应该看到
从“应用程序”启动后出现欢迎或登录界面。
卡在这一步？

如果提示“已损坏”或无法验证：先核对来源并重新下载官方包，查看官方支持；不要执行网上的关闭系统保护命令。仅提示版本不支持时回到第 1 步。

03
Mac · ChatGPT 桌面应用

登录，并找到 Codex 模式

  1. 打开应用，点击登录（Sign in / Log in），用自己的 ChatGPT 账户完成登录。若跳到浏览器，在浏览器完成后返回桌面应用；出现“打开应用”的返回提示时，核对是刚安装的应用再打开。
  2. 没有账户时，在官方登录页选择注册，按页面完成邮箱验证或所选登录方式；已有账户保持原来的登录方式。课程不提供账号，密码、验证码只填官方登录流程。
  3. 在应用的 ChatGPT 下拉选择中切到 Codex。本课使用 Codex 的本地文件任务；不用 Quick chat。若你已经在名为 Codex 的旧版应用中，先核对更新与当前官方入口。
  4. 选择账户中当前可用的默认模型即可，不需追求特定型号。先完成下方小检查，再决定是否需要额外额度；课程费用不包含工具订阅或使用费。
做到这里，应该看到
桌面应用已登录，可以选择 Codex 并看到新建对话入口。仅浏览器显示登录成功还不够。
卡在这一步？

登录后仍停在欢迎页：返回桌面应用重试登录，并确认用的是同一账户。没有 Codex 入口：更新官方应用、确认账号/组织权限；先解决入口，再做后续文件操作。

07
Codex · 先只读，不修改

先证明它打开的是正确目录

这是首次安装后的只读检查，请实际使用文件工具，不凭聊天内容猜测。
1. 报告当前工作目录的完整路径。
2. 只列出当前目录第一层的文件与文件夹，不递归搜索。
3. 如果当前目录直接包含 START.txt，读取它并引用第一句话；否则停止并说明缺少什么，不自动寻找别的目录。
这一步不要创建、修改或删除文件，不联网，不读取工作区之外的资料。
自己核对三项
① 完整路径是你解压后选中的 workspace。
② 一级目录包含 inbox、context、resources、outputs、checks。
③ 引用 START.txt 的第一句话含“这是 Personal Agent 课程练习目录”。

路径可能包含中文或不同盘符，都可以；关键是与你实际选中的目录一致。缺一项就回到选目录步骤，不继续写入。

只创建一个小文件

请先确认当前目录直接包含 START.txt，且刚才已成功读到它。否则停止。
只在当前目录的 outputs 下创建 setup-check.md，内容为以下三行：
# 我的第一次读写检查
这是课程安装练习，不是真实业务资料。
下一步：返回课程学习。
如果同名文件已存在，先读取并报告，不覆盖、不另建副本。
写入后重新读取真实文件，展示实际内容与完整路径。不要改其他文件，不安装软件，不联网。
应该看到
真实文件写入和重新读取的结果，以及 outputs/setup-check.md 的完整路径。若权限不足，先解决请求或报错。若文件已存在，核对已有内容即可，不覆盖。

WHEN SOMETHING GOES WRONG

按你看到的问题，回到正确的一步。

我只看到 ChatGPT 网页，找不到本地目录

确认是从应用程序 / 开始菜单打开桌面应用，再切到 Codex。网页附件上传与授权本地文件夹是两件事。回到本平台第 2、3 步。

登录成功却找不到 Codex，或提示没有额度

先更新官方应用，核对账号和组织是否提供 Codex。额度用尽按账户的重置或方案提示处理；不要反复发送测试。课程本身不包含工具额度。

下载完成却找不到 ZIP

打开浏览器下载列表，使用“在 Finder / 文件夹中显示”。Mac 可能已自动解压；Windows 需完成“全部解压”。不要重复创建多个不清楚的副本。

Codex 报告的路径不对，或 START.txt 不存在

停止写入。在系统文件管理器找到直接包含 START.txt 的 workspace；重新选择该文件夹，在它的新任务中重做只读检查。不要让 AI 搜索整台电脑来弥补选错目录。

有两个 workspace，究竟用了哪个

比较 Codex 报告的完整路径与文件管理器地址。Mac 在 Finder 的“显示”菜单开启“显示路径栏”；Windows 点击资源管理器地址栏查看完整路径。重名不等于同一个文件夹。

只有聊天里的文字，outputs 里没有文件

确认当前任务有文件工具与工作区写权限；在同一任务单独发写入指令。若工具报错先解决错误，不能把聊天回复“已保存”当成成功。

文件存在但打不开，或打开的是别的副本

让 Codex报告产出的完整路径，在 Finder / 资源管理器沿该路径打开。用文本编辑器（Mac 文本编辑 / Windows 记事本）打开 .md；也可使用应用文件预览。

Windows 没有 python3，后续检查器还能用吗

先发下方“可选检查器”指令，仅检测已有 Python。Windows 常见命令为 py -3 或 python，Mac 常见 python3；有 Python 3 才运行。没有时用课程人工验收表，不把未运行写成已通过。

看不到 .agents 或后缀不对

这是第 6 课才安装的目录，新包没有它是正常的。Mac 用 ⌘+Shift+. 切换隐藏文件显示；Windows 在“查看 → 显示”开启隐藏的项目和文件扩展名。检查 SKILL.md，而非 SKILL.md.txt。

重开应用以后，还要重装一遍吗

不用。打开同一 workspace 项目或重新选择原目录，创建新任务。先让工具读 START.txt 验证路径，再继续课程。不要把“新任务”理解成新建一套文件夹。
